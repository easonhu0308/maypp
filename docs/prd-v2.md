# 懂你紫微 v2 PRD：越來越懂你的身心靈紫微 App

## 產品願景
「懂你紫微」不是一次性的算命工具，而是一位**越來越懂你**的命理夥伴。它用紫微斗數的格局與流日變化作為對話脈絡，結合使用者的心情、打卡與提問，產出**有根據、有溫度、可執行**的每日指引。

## 核心設計原則
1. **看得見的推理**：每一句建議都要讓使用者知道「從哪裡來」，避免黑箱感。
2. **正向框架**：不講厄運、不恐嚇，所有內容導向覺察與行動。
3. **漸進式懂你**：透過打卡、提問、回饋，App 會越來越貼近個人狀態。
4. **最小可互動單位**：每個頁面都有至少一個「可以做」的下一步。

---

## 使用者旅程（Happy Path）

| 步驟 | 畫面 | 目的 |
|------|------|------|
| 1 | 歡迎頁 | 建立「陪伴感」而非「工具感」 |
| 2 | 建立命盤 | 收集生日、時辰、性別、暱稱與身心靈目標 |
| 3 | 今日頁（Home） | 每天一打開就能看到「今天為什麼是這樣」+ 行動建議 |
| 4 | 命盤頁 | 探索自己的格局、主星、宮位意義 |
| 5 | 問事／報告 | 針對具體問題產出帶推理的命理解讀 |
| 6 | 打卡與時間軸 | 記錄心情，讓後續建議更貼近真實生活 |

## 頁面規格

### 1. 歡迎頁（Welcome）
- 文案：「每個人都有自己的星圖。我們一起慢慢讀懂它。」
- 單一主按鈕：「開始認識自己」
- 底部輕聲明：資料存在手機、不占卜醫療投資。

### 2. 建立命盤（Onboarding）
欄位：
- 暱稱
- 國曆生日、出生時間
- 性別（用於 iztro 運算，「其他／不透露」以男計，可註明）
- 身心靈目標（多選）：穩定情緒、改善睡眠、工作方向、關係理解、財務規劃、自我認識
- 三項同意（簡潔版）：個人化內容、AI 日報、匿名改善體驗

### 3. 今日頁（Today）— 核心首頁
區塊：
1. **今日懂你的開場**：「早安，{暱稱}。今天是 {日柱}，你的命宮主星 {主星} 正與 {流日宮位} 對話。」
2. **動態推理卡**：用 2-3 句話說明今天運勢的「命理依據」：流日走到哪一宮、引動哪些星曜、對應生活領域。
3. **能量指數**：1-100 視覺化，說明計算來源（結合命盤流日 + 近 7 日心情平均）。
4. **三維指引**：事業／感情／財運，每個維度給一句「原因 + 行動」。
5. **宜做與幸運**：3 個今日宜做 chips、幸運色/數字/方位。
6. **給你的一句話**：結合近 7 日打卡標籤，回應具體狀態。
7. **底部 CTA**：「今天過得如何？」快速打卡。

### 4. 命盤頁（Chart）
- **主視覺**：保留 12 宮格，點擊任一宮開啟宮位詳解。
- **格局速讀**：「一句話看懂你的格局」置頂。
- **頁籤**（Tab）：
  - 命盤（預設）
  - 主星（命宮主星組合解析）
  - 流年（本年度大運與流年重點宮位）
- **問事入口**：右下角浮動按鈕「問一件事」，把命盤資訊帶入問事頁。

### 5. 問事／報告（Ask / Reports）
把「報告」從靜態列表改成**以問題驅動的動態解讀**。

問事流程：
1. 選擇領域：事業、感情、財運、健康、人際、年度運勢
2. 輸入具體問題（可選，例如「這週適合提案嗎？」）
3. 系統結合命盤、流日、打卡記錄產出一份「懂我報告」

報告內容結構：
- 問題重述
- 命理觀點：引動哪些宮位與星曜
- 從你最近的狀態來看：回應打卡標籤或心情趨勢
- 可以怎麼做：2-3 條具體行動
- 提醒：非醫療/投資建議

報告列表：
- 不再放錯誤靜態文案，而是顯示已產生的問事紀錄，標題為問題摘要。

### 6. 打卡與時間軸（Check-in / Timeline）
- 打卡頁簡化為 1-5 心情 + 3 個情緒標籤 + 一行文字。
- 時間軸頁：以日曆/列表混合顯示心情與當日一句話，提供「越來越懂你」的洞察（例如「你最近有 4 天標到『工作卡關』，要不要看看事業運？」）。

### 7. 我的與隱私（Profile / Privacy）
- 顯示命盤摘要與身心靈目標
- 開關：個人化、AI 雲端日報、推播、匿名統計
- 匯出資料 / 刪除資料
- 聯絡與回饋入口

## 技術對應

| 產品需求 | 現有基礎 | 需補強 |
|----------|----------|--------|
| 動態推理文案 | `daily.js` 本地模板 | 在 prompt 中明確要求列出「引動宮位 + 星曜 + 生活領域」 |
| 問事報告 | 無 | 新增 `/api/ask` 與 `AskScreen`、儲存 `ziwei.reports` |
| 命盤宮位詳解 | `astro.js` 已輸出宮位資料 | 新增宮位與主星解釋對照表 |
| 流年運勢 | 無 | 用 iztro 取大運/流年資料，簡化為「重點宮位」 |
| 越來越懂你 | `ziwei.checkins` | 增加標籤統計與主動提示 |

## 短期優先順序（MVP v2.1）

1. 重做「今日頁」文案結構，強制帶入推理句。
2. 修正「報告頁」：移除錯誤靜態內容，改為「問事 → 產生報告 → 列表」。
3. 命盤頁新增「宮位點擊詳解」與「問事入口」。
4. 打卡後回到今日頁，立刻讓文案回應當天心情。

長期（v2.2）：流年運勢、主動洞察推送、更細緻的個人化 prompt。
